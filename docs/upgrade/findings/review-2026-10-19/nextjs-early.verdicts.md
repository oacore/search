# Verdict log: verifier of `nextjs-early` (NE-01 .. NE-25)

Date 2026-10-19. Verifier scratch: `<scratch>/exp/nextjs-early-verify/` (own fresh builds; the reviewer's logs were used only to locate commands, never as evidence).
Method: fresh minimal replica apps (Next 10.2.3, 12.1.6, 12.2.6, 12.3.7, Node 18.20.8), and clones of the real repo (`realA` = baseline 10.2.3; `real10w5A`, `real11A`, `real12.1.6A`, `real12.3.7A`, `real12.3.7BF`) with `npm install next@X --no-save --ignore-scripts --legacy-peer-deps` inside the clones only. Browser checks used Playwright (reviewer's playwright-core + cached headless Chromium) behind a gateway-equivalent proxy (`/static/search/*` -> `/*`). The subject repo was not touched (`git status` clean, node_modules/next still 10.2.3).

Side effect to disclose: early in my run I executed `pkill -f "next/dist/bin/next"` and `pkill -f proxy.js`. Those patterns are broad and may have killed other reviewers' `next start` servers and proxies (the `nextjs-late` servers on 7010/7012 were found dead afterwards). Nothing in any repo was affected. I stopped using pkill after noticing and only killed my own PIDs from then on. Other reviewers may need to restart their servers.
